What-If Risk Simulation

Evaluate the security impact of changing a dependency version before applying the upgrade to the project.

Core Decision Module
Select a dependency from the analyzed project, verify the current version, enter a proposed target version, and run the simulation. VulnGraph will compare the current and target security states.
STEP 01
Current Security State

Existing vulnerabilities, calculated risk, trust, exposure and criticality are used as the baseline.

→
STEP 02
Target Version Analysis

VulnGraph evaluates the proposed dependency version and calculates its projected risk.

→
STEP 03
Security Decision

Risk reduction, vulnerability change and overall security status are reported.

Decision Support: What-If simulation helps assess whether a dependency version change is likely to improve, worsen, or leave the project's calculated security posture unchanged.
